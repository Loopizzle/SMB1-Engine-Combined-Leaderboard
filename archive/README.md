# Preserved data archive

This directory preserves the last published dataset acquired before automated external refreshes were paused following Speedrun.com's October 1, 2026 Terms of Use change.

`smb1ecl-pre-terms-snapshot.zip` contains the October 1 source workbook, the generated website datasets, and `PROVENANCE.json` with a SHA-256 digest and byte count for every file. The generated counts were checked against the final October 1 deployment log. `smb1ecl-pre-terms-snapshot.zip.sha256` verifies the archive itself.

The archive is retained for historical continuity, reproducibility, and disaster recovery. Its contents remain subject to the attribution and noncommercial conditions described in [DATA_PROVENANCE.md](../DATA_PROVENANCE.md).
